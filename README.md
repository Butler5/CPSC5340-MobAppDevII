# iOS Mobile Application Projects

A collection of Swift-based iOS projects covering native mobile application development. The repository includes a final project and smaller exercises involving notes, currency/cryptocurrency conversion, and an emoji counter.

## Project areas

- **FinalProject** — primary mobile application project, organized into model and view folders with unit/UI test targets.
- **Notes** — notes application exercise.
- **CryptoConvert** — cryptocurrency conversion exercise.
- **Emoji Counter** — small interactive iOS application.
- **Assignment 3** — additional iOS development exercise.

## Technology

- Swift
- Xcode
- iOS SDK
- XCTest and UI testing

## Run locally

1. Install Xcode on macOS.
2. Clone this repository.
3. Open the desired `.xcodeproj` file from its project folder.
4. Select an available iOS simulator or connected device.
5. Build and run the selected scheme.

## Tests

Where test targets are included, run them through Xcode's Test action. Test coverage and current simulator compatibility should be verified for each project.

## Status

Educational project collection. The projects are preserved as separate exercises; the final project is the recommended starting point for reviewing the more substantial application work. Add screenshots and verified feature descriptions after testing.
